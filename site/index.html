Instalar

Para Ubuntu com GNOME Shell 50 (Wayland). As atualizações chegam junto com as do sistema.

curl -fsSL https://gustavoreimche.github.io/gprengine-gnome/gprengine.gpg | sudo tee /usr/share/keyrings/gprengine.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/gprengine.gpg] https://gustavoreimche.github.io/gprengine-gnome stable main" | sudo tee /etc/apt/sources.list.d/gprengine.list
sudo apt update && sudo apt install gprengine

Depois saia e entre na sessão e ative a extensão:

gnome-extensions enable gprengine@gpr

Prefere o arquivo? O .deb de cada versão está em Releases.

Escreva um wallpaper

Uma função que devolve a cor de cada pixel. O tempo faz a animação.

No app: + › Criar um wallpaper…. Ele cria a pasta, aplica e abre o arquivo; cada vez que você salva, o fundo recarrega.

Ler o guia completo

void mainImage(out vec4 fragColor, in vec2 fragCoord) {
    vec2 uv = fragCoord / iResolution.xy;
    float onda = 0.5 + 0.5 * sin((uv.x + uv.y) * 6.0 + iTime * 0.4);
    vec3 noite = vec3(0.05, 0.07, 0.16);
    vec3 aurora = vec3(0.95, 0.45, 0.35);
    fragColor = vec4(mix(noite, aurora, onda * uv.y), 1.0);
}
